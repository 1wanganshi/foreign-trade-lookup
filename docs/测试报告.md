### 4.3 为什么这样算"极简"

1. **只加 3 行**：答案卡总高约 340 px（含内边距），占首屏 40%，用户无需滚动即可读完三问。
2. **零新增交互**：答案卡不可点击、无展开、无悬浮，纯静态文本。
3. **职责单一**：答案卡只回答"结论"，细节仍留在原页签里，不重复展开。
4. **降噪**：未收录产品隐藏摘要与相关产品，提示压缩成一行。
5. **能力扩展不外露**：知识库从 110 扩到 152、术语表 279 条，页面元素数量、层级、交互全部未变——扩充只影响"命中率"，不影响"看得懂"。

## 五、三项固定顺序的答案（本次测试输入：我是做饼干机器的）

1. **哪个国家 / 哪个地区比较合适**：首选 **巴西（拉丁美洲）**，其次 **智利**；区域看 **拉丁美洲**。
2. **为什么合适**：新兴市场烘焙连锁与中央厨房扩张、整线设备依赖进口；同时当地清关与税制复杂，通常走本地仓/墨西哥转口，需要备货与代理配合。
3. **投流还是自然流更好**：**自然流为主**（B2B 信任驱动）。投流只做高意图长尾词（占总预算 20–30%）；主力是展会（IBA/Gulfood）+ 海关数据找进口商 + 领英定向开发。

> 该结论来自「烘焙与食品加工设备」品类规则推断（中等置信度），非知识库人工结论，页面已用黄色徽标与提示行标注。

## 六、已知限制

1. **多义与品牌词**（Amazon / 苹果 / 小米 / 做外贸的）只能给"品类推断"或明确提示，无法给出具体产品结论——不做无依据猜测。
2. **超过 40 字的输入**直接提示换词，长英文别名需拆词查询。
3. **联网兜底在本机不可用**（网络无法直连 Google/Bing/DDG/Wikipedia）。此时页面明确显示"仅来自本地规则推断"，不伪造来源；配 `TAVILY_API_KEY` 或 `SERPER_API_KEY` 后生效。
4. **heat 热度**是人工标定的相对优先级，不是真实贸易额。
5. **品类池结论**为规则推断（medium），与知识库条目（high）在视觉上已区分，不可当成同等级结论使用。
