# 部署说明

本项目有两种部署形态，**能力不同**，先看选择：

| 部署方式 | 知识库查询 | AI 兜底（检索+推断） | 适用 |
|---|---|---|---|
| **A. GitHub Pages（纯静态）** | ✅ 可用 | ❌ 不可用 | 只需秒查已收录的 156 个产品 |
| **B. 服务器 / 容器（推荐）** | ✅ 可用 | ✅ 可用 | 需要查未收录产品、AI 自动补全 |

---

## A. GitHub Pages（静态托管）

Pages 只能托管静态文件，`server.mjs` 不会运行，因此：

- ✅ 156 个内置产品秒出结果（纯前端计算）
- ❌ 未收录产品只能显示"未收录"，不会有 AI 补全

启用方式：仓库 Settings → Pages → Source 选 `master` 分支，目录选 `/web`。

访问地址：`https://1wanganshi.github.io/foreign-trade-lookup/`

---

## B. 服务器部署（完整功能）

### 1. 环境要求
- Node.js **>= 18**（需要内置 fetch）

### 2. 拉取并安装
```bash
git clone https://github.com/1wanganshi/foreign-trade-lookup.git
cd foreign-trade-lookup
cp .env.example .env
```

### 3. 配置 .env
```ini
AI_API_KEY=sk-xxx
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini

TAVILY_API_KEY=tvly-xxx
SEARCH_PROVIDER=tavily
```

### 4. 启动
```bash
npm start
# 默认 http://localhost:8787
PORT=8080 npm start   # 换端口
```

### 5. 反向代理（示例 Caddy）
```
lookup.example.com {
    reverse_proxy localhost:8787
}
```

---

## 验证部署是否成功

```bash
curl http://localhost:8787/api/health
```

期望输出：
```json
{ "ok": true, "provider": "tavily",
  "keys": { "tavily": true }, "ai": true, "aiModel": "gpt-4o-mini" }
```

`ai: false` 表示没配 AI Key，此时未收录产品只走本地规则。

## 安全提醒

- Key 泄露后请立即在对应平台吊销并更换
